# AccessMod design system

Reference for building the AccessMod web client (Rust rewrite). The goal is
that AccessMod 5 users find their way: **same sections, same layout, same
vocabulary, same look**. The only visual addition is a dark theme.

Stack: React 19, TypeScript, Vite, Tailwind v4, shadcn/ui (Radix), Lucide,
Tabulator (tables), MapLibre (maps), Source Sans 3.

## Rules

1. **Tokens only.** No raw colours, no arbitrary greys. Use the Tailwind names
   that map to tokens (`bg-well`, `border-panel-border`, `text-link`,
   `text-muted-foreground`, …). A colour that is missing becomes a new token,
   defined in both `:root` and `.dark`.
2. **No hard-coded text.** Every label goes through `t(key)` or `<T k>`. Use
   the AM5 key when one exists (search `catalog.json` or the screen's
   `meta.json`). New keys go in `src/i18n/own.json` with dotted names
   (`table.all`), all four languages, never colliding with AM5 keys; then run
   `cargo xtask i18n` (the gate runs `--check`). `Key` is a typed union: an
   unknown key is a compile error.
3. **Patterns before primitives.** Use `components/am` first. Use shadcn
   primitives directly only when no pattern fits; if one fits twice, add a
   pattern.
4. **Icons through `icons`.** Use semantic names (`icons.delete`), not Lucide
   imports, so the AM5 mapping stays in one place.
5. **Square and dense, like AM5.** Buttons, panels and tabs have no radius;
   inputs, selects and wells use `--radius` (4px). Body is 14px with a line
   height of 1.43. Do not add shadcn's roomier spacing.
6. **Both themes.** Check every screen inThe design system is the npm workspace package `@accessmod/ui`; the web
client (`web/`, `@accessmod/web`) imports its sources (`@accessmod/ui/am/*`,
`/ui/*`, `/i18n`, `/theme`, `/styles.css`). Inside the package, imports use

## Maps

MapLibre for the Project location map and Toolbox › Interactive map.

- **Basemap**: offline and schematic: one PMTiles archive with a
  `countries` polygon layer (`public/basemap/countries.pmtiles`, built by
  `design-system/scripts/build-basemap.sh` from any countries file).
  `schematicStyle()` draws land, water and borders from the `map-*` tokens
  and repaints when the theme changes. There are no labels, glyphs or network
  requests. The demo archive is Natural Earth 1:110m (455 KB, z0–6); for
  production pick a finer source (Natural Earth 1:10m, geoBoundaries ADM0).
- **Controls**: React buttons on the map, themed with the tokens and
  translated, with tooltips. Zoom and home (back to the project extent) sit
  top-left; the scale is bottom-left and the attribution bottom-right.
- **Facility editing** (Interactive map): pass `editing` to show the top-right
  group: pen (toggle move mode), next facility, undo, redo. The design
  system only provides the buttons and their states; the move tool itself
  (dragging a facility a few metres off a barrier at high zoom, from the
  raster) belongs to the client.
- **Layers**: add sources and layers in `onLoad`. AM5 symbology: travel time
  in viridis, facilities as green markers (`#5cb85c`), project extent as a
  primary-coloured outline.

## Deliberate deviations from AM5

- **Contrast**: link, callout, danger, warning and muted text are darkened
  in light mode to pass AA. The hues are unchanged.
- **Radius**: AM5 mixed square text inputs with 4px selects; both are 4px now.
- **Icons**: Lucide outline icons instead of Font Awesome solid icons
  (`docs/icons.md`).
- **Maps**: MapLibre instead of Leaflet, offline schematic basemap instead
  of MapTiler, and modern grouped controls instead of the Leaflet ones.
  Redo is new (AM5 had undo only).
- **Table toolbar labels** ([All] [None] [Select] [Unselect]) were
  English-only in AM5. They are translated now (`own.json`).
- **Dark theme**: new.

## Refreshing the references

```
cd scripts/capture && npm install
npm run capture                 # needs AM5 at http://localhost:3080 (AM5_URL)
node capture.mjs data-import    # single screen
CROPS_ONLY=1 node capture.mjs   # component crops only
```

The script opens the `demo` project (`AM5_PROJECT`) and picks the first
option of empty selects on Analysis and Toolbox screens. It never clicks
import, delete, rename, archive or compute, and it reopens the project and
language you had before. Screens can also pick options by label, type a
value, open a sub-tab or click read-only update buttons (step kinds are
listed at the top of `screens.mjs`). Zonal statistics, for instance, picks
`travel time [ca]`, types `1351` (the default `0` is rejected) and clicks
**Update**, which computes a read-only table.
